# Personal Portfolio Website

A responsive personal portfolio website built with HTML, CSS and JavaScript. It introduces me, lists my skills and links to my projects on GitHub.

## Sections
- Hero with a short introduction
- About
- Skills
- Projects (with links to code)
- Contact

## Features
- Fully responsive (works on mobile and desktop)
- Navigation highlights the section you are reading
- Keyboard-friendly focus styles
- Respects the "reduce motion" setting

## Built with
- HTML5
- CSS3 (custom properties, flexbox)
- JavaScript (IntersectionObserver)

## How to run
1. Download or clone this repository
2. Open `index.html` in any browser
